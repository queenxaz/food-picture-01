# Tonkotsu, perfected — the noodle pull

A food-picture-01 entry for make.fun: one hero dish, shot to make the
viewer hungry.

The picture is a steaming bowl of tonkotsu ramen at the moment of the
pull: wooden chopsticks lift a tall, glossy strand of noodles out of
the broth, a halved jammy egg spills its yolk, chashu, nori and
spring onions sit in a speckled dark bowl, steam curling up against a
dark, moody background with warm bokeh.

No concept, no gimmick — just the dish, close up, at its most
appetising. The program writes the image byte-identical to
`/output/entry.png` (Python 3.13 standard library only, deterministic,
no network, no model calls). Run it locally with
`MAKEFUN_OUTPUT_DIR=out python3 main.py`.
